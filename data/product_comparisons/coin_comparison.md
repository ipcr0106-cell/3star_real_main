# 코인육수 4종 비교 가이드

YUKDAM(육담) 코인육수는 매일 끓이는 베트남 국물 요리에 코인 1알만 넣으면 한국식 깊은 맛이 더해지는 '국물 부스터'입니다. 4종 모두 25알/팩, 250g 기준입니다.

## 한눈에 비교

| 가격 | ₫89,000 | ₫85,000 | ₫85,000 | ₫92,000 |
| 매운 강도 | ★★★☆☆ | ☆☆☆☆☆ | ★★★☆☆ | ★★☆☆☆ |

| 비건 | ❌ | ❌ | ✅ 100% 비건 | ❌ |

| 추천 상황 | 진하고 얼큰한 국물을 원할 때 | 어떤 요리에든 부담 없이 감칠맛만 더하고 싶을 때 | 채식의 날(ngày rằm) 또는 비건 식단, 한국식 매운 국물 | 베트남 남부식 새콤탕(Canh chua)에 발효 깊이를 더하고 싶을 때 |

## 이런 분께 추천

- **"처음 써보는데 뭐부터?"** → coin_02 멸치 (가장 범용적, 맛이 순해서 어떤 요리에든 실패 없음)
- **"한국식 매운맛 좋아해요"** → coin_01 육개장 (소고기+고추의 얼큰한 맛, Phở·Lẩu에 가장 인기)
- **"채식주의자예요"** → coin_03 매콤채수 (100% 식물성 비건, MSG 무첨가)
- **"베트남 현지 맛에 가깝게"** → coin_04 김치타마린 (타마린의 익숙한 산미 + 김치 발효의 새로운 깊이)
- **"아이가 먹어요"** → coin_02 멸치 (매운맛 없음, 가장 순하고 담백)
- **"MZ세대 / SNS 트렌드"** → coin_03 매콤채수 (한국식 해장국 트렌드, 비건 트렌드 동시 충족)
- **"남부 지방에 살아요"** → coin_04 김치타마린 (남부 Canh chua 문화에 최적화)

## 조합 활용

두 종류의 코인을 함께 사용하면 단일 코인으로는 만들 수 없는 복합 풍미를 구현할 수 있습니다.

- **coin_01 + coin_04** = 매콤새콤 프리미엄 전골 — 육개장의 얼큰함 + 김치타마린의 새콤함이 겹쳐 깊은 매콤새콤 전골 육수
- **coin_02 + coin_03** = 담백한 비건 국수 — 멸치의 자연 감칠맛 + 채수의 칼칼함으로 비건이지만 깊은 맛 (※ coin_02는 멸치 함유로 엄격한 비건에는 비적합)
- **coin_01 + coin_02** = 얼큰 담백 밸런스 전골 — 육개장의 매운맛을 멸치의 맑은 감칠맛이 중화
- **coin_02 + coin_04** = 맑은 새콤탕 — 멸치의 담백함 + 타마린의 산미로 깔끔한 새콤 국물

## 공통 사용법

1. 물 500ml(1인분)당 코인 1개, 전골·Lẩu는 물 1L당 코인 2개
2. 끓는 물에 코인을 넣고 저어서 완전히 녹인 후 재료 추가
3. 기존 요리를 대체하는 것이 아니라 '한 층 더' 얹어주는 부스터로 사용
4. 개봉 후 지퍼백 밀봉, 서늘한 곳 보관, 3개월 이내 사용
