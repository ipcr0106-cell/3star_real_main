# SONMAT 시즈닝 4종 비교 가이드

SONMAT(손맛) 시즈닝은 뿌리기만 하면 한국식 맛이 완성되는 가루 시즈닝 라인입니다. 요리 양념으로도, 과자·과일 위에 뿌려 간식으로도, 밥 위에 짜봉(Chà bông)처럼 올려서도 활용할 수 있는 이중 용도 제품입니다. 모든 제품은 300g/팩 기준입니다.

## 이런 분께 추천

- **"처음 사는데 뭐부터?"** → season_01 불고기 (가장 범용적, 아이~어른 모두, 매운맛 없음)
- **"한국 치킨 좋아해요!"** → season_03 닭갈비 (K-치킨 매콤달콤, 닭구이에 뿌려 재우면 끝)
- **"구수한 국물이 좋아요"** → season_02 감자탕 (된장+들깨의 한국 전골 풍미)
- **"보양식/고급스러운 맛"** → season_04 전복죽 (제주산 전복, 프리미엄 보양식 1분 완성)
- **"아이가 먹어요"** → season_01 불고기 또는 season_04 전복죽 (매운맛 없음)
- **"자취생이에요"** → season_04 전복죽 (뜨거운 물만 부으면 한 끼) + season_01 불고기 (밥에 뿌리면 끝)
- **"SNS 요리 콘텐츠"** → season_03 닭갈비 (빨간 색감, K-치킨 트렌드)

## 시즈닝 조합 활용

- **season_01 + season_03** = 불고기 시즈닝으로 밑간 + 닭갈비 시즈닝으로 마무리 = 달짠매콤 이중 양념 구이
- **season_02 + season_04** = 감자탕 시즈닝 죽 + 전복죽 시즈닝 토핑 = 돼지뼈+전복의 초호화 죽
- **season_01 + season_02** = 불고기 시즈닝 볶음밥 + 감자탕 시즈닝 국 = 한국 가정식 한 상 완성

## 코인육수 vs 시즈닝 — 언제 뭘 쓰나요?

| 상황 | 코인육수 (YUKDAM) | 시즈닝 (SONMAT) |
|------|-----------------|----------------|
| 국물 요리 (Phở, Canh, Lẩu) | ✅ 국물 베이스 전용 | △ 부가적으로 사용 가능 |
| 구이/볶음 양념 | ❌ | ✅ 고기에 뿌려 재우기 |
| 밥 토핑 / 간식 | ❌ | ✅ 짜봉처럼 뿌리기 |
| 즉석 죽/수프 | △ 국물 베이스로 | ✅ season_04로 즉석 완성 |
| 전골 육수 | ✅ 코인 녹이면 끝 | ✅ season_02로도 가능 |

## 공통 사용법

1. 구이/볶음: 고기에 시즈닝을 뿌려 10~20분 재운 후 조리
2. 밥 토핑: 뜨거운 밥 위에 짜봉/후리카케처럼 뿌려서 바로 섭취
3. 스낵: 과자·감자튀김·과일 위에 직접 뿌리기
4. 개봉 후 입구 밀봉, 서늘하고 건조한 곳 보관, 습기 주의, 3개월 이내 사용
