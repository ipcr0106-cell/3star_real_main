# PUNGMI 소스 6종 비교 가이드

## 용도별 추천 — "이 요리에는 이 소스!"

| 요리/상황 | 추천 소스 | 이유 |
|-----------|----------|------|
| **Bánh mì (반미) 발라먹기** | sauce_01 청양마요 | 크리미한 마요가 빵에 촉촉함, 매운맛이 고기·절임채소와 조화 |
| **해산물 찜/구이 찍어먹기** | sauce_02 매실디핑 | 매실 산미가 비린맛 중화, 피쉬소스가 해산물 감칠맛 시너지 |
| **Gỏi cuốn (월남쌈) 디핑** | sauce_03 쌈장허브 | 된장의 감칠맛이 라이스페이퍼의 담백함을 받쳐줌, 허브와 조화 |
| **볶음면/볶음 쌀국수** | sauce_04 K-로제 | 크림+고추장이 면에 코팅, 레몬그라스가 느끼함 중화 |
| **숯불구이/바비큐** | sauce_05 불코코넛BBQ | 마리네이드+글레이징 겸용, 코코넛이 카라멜화되어 윤기 |
| **치킨윙/튀김 버무림** | sauce_06 망고고추장 | 망고+고추장의 달콤매콤, 튀김에 코팅되는 글레이즈 효과 |
| **샐러드 드레싱** | sauce_01 또는 sauce_02 | 크리미한 드레싱=sauce_01, 새콤한 드레싱=sauce_02 |
| **구이 고기 디핑** | sauce_03 또는 sauce_05 | 채소에 싸서=sauce_03, BBQ 스타일=sauce_05 |

## 이런 분께 추천

- **"매운 거 좋아해요!"** → sauce_01 청양마요 (크리미하면서 칼칼한 한국식 매운맛)
- **"해산물을 자주 먹어요"** → sauce_02 매실디핑 (해산물 전용, 매실의 프리미엄 산미)
- **"월남쌈/쌈을 자주 해요"** → sauce_03 쌈장허브 (기존 땅콩소스·느억맘을 대체하는 한국식 디핑)
- **"볶음 요리에 새로운 맛을"** → sauce_04 K-로제 (한국에서 가장 핫한 로제 트렌드를 집에서)
- **"바비큐/구이를 즐겨요"** → sauce_05 불코코넛BBQ (마리네이드+글레이징 겸용)
- **"K-치킨을 집에서!"** → sauce_06 망고고추장 (프랜차이즈 양념치킨 맛을 집에서 재현)
- **"아이가 함께 먹어요"** → sauce_02 매실디핑 또는 sauce_05 불코코넛BBQ (매운맛 가장 약함)
- **"계란 알레르기가 있어요"** → sauce_01 제외 나머지 5종 모두 가능

## 소스 조합 활용

- **sauce_01 + sauce_06** = Bánh mì 위에 청양마요 + 망고고추장 이중 소스 → 달콤매콤크리미
- **sauce_03 + sauce_05** = 쌈장 디핑 + 불코코넛 글레이즈 구이 → 완벽한 쌈 세트
- **sauce_02 + sauce_04** = 매실디핑 해산물 + K-로제 볶음면 → 해산물 코스 완성

## 공통 사용법

1. 스퀴즈 보틀 뚜껑을 열고 직접 짜서 사용
2. 디핑 시 소스 그릇에 덜어서 찍어먹기
3. 개봉 후 반드시 냉장 보관 (30~45일 이내 사용)
4. 흔들어서 사용하면 내용물이 더 균일하게 섞임
